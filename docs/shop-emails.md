# Shop の定型メール（Fade, Stay）

Stripeが自動で送るのは **購入者への領収書メール** と **自分への支払い完了通知** の2通だけ。
**発送の連絡はStripeからは一切出ない**ので、ここのテンプレートを使って手で送る。

文面を直すときは、以下と食い違わないか確認する。
**正典は `src/lib/shop.ts` の定数**（`SHIPPING_DAYS` / `SHIPPING_METHOD` / `COVER_PHOTO_POLICY`）で、
`/shop` と `/tokushoho` はそこから引いているので放っておいても揃う。
**このファイルだけはコードから生成していない**（人が読んで貼るテキストなので）＝
shop.ts を変えたらここも手で直す。あとは実際の運用が合っているか。

- 発送の期限 = ご注文確認後5営業日以内（土日祝を除く）
- 不良の連絡期限 = 商品到着後7日以内
- 不良品 = 返送不要・写真を送ってもらって交換（在庫がなければ全額返金）
- 手貼り表紙の剥がれ・浮きは不良ではない

件名の `【Fade, Stay】` は、サイトのmailtoの件名と揃えてある。
Gmailで `【Fade, Stay】` を条件にフィルタ→ラベルを作れば、3事業のメールに埋もれない。

## 1. 発送のお知らせ（毎回送る）

**件名:** `【Fade, Stay】発送しました`

```
{お名前} 様

このたびは「Fade, Stay」をお求めいただき、ありがとうございます。
本日、ご注文の品を発送しました。

  配送方法  レターパックライト（日本郵便）
  追跡番号  {追跡番号}

追跡は日本郵便のページで確認できます。
https://trackings.post.japanpost.jp/services/srv/search/input

お届けまでは、地域により2〜4日ほどかかります。

表紙の写真は1冊ずつ手で貼っています。
時間が経って剥がれることを想定した作りなので、
剥がれや浮きは不良ではありません。

万一、本体の破れや汚れなど、届いた状態に問題がありましたら、
商品到着後7日以内にこのメールへご返信ください。
状態がわかる写真をお送りいただければ、ご返送は不要で交換品をお送りします。

鈴木 拓人
https://www.takutosuzuki.com
```

差し替えるのは `{お名前}` と `{追跡番号}` の2箇所だけ。
宛先と配送先住所は Stripeダッシュボードの「取引」から該当の決済を開くと出る。

## 2. 不良の連絡が来たときの返信

**件名:** 相手のメールにそのまま返信（件名は変えない）

```
{お名前} 様

ご連絡ありがとうございます。
また、お手元に届いた状態でご不便をおかけして申し訳ありません。

状態を確認したいので、お手数ですが該当箇所の写真を1〜2枚、
このメールにご返信いただけますでしょうか。
確認しだい、交換品をお送りします。

お手元の品はご返送いただく必要はありません。そのままお納めください。

鈴木 拓人
```

**「着払いで送ってください」とは絶対に書かない。** 着払いは宅配便扱いになり、
60サイズで800〜1,000円かかる。交換品を送るほうが安く済む（1件約1,410円）。

## 3. 在庫がなく返金する場合

```
{お名前} 様

ご連絡ありがとうございます。
交換品をご用意したかったのですが、在庫が尽きてしまいました。

代金 {金額} 円を全額返金いたします。
ご返金はStripeを通じて、お支払いに使われたカードへ行われます。
反映まで5〜10営業日ほどかかる場合があります。

お手元の品はご返送いただく必要はありません。

鈴木 拓人
```

返金の操作は Stripeダッシュボードの「取引」→ 該当決済 →「返金」。

**返金しただけでは枠を戻さない。** 戻すのは「もう一度売れる本が手元にある」ときだけ:

- 発送前にキャンセル・返金した（本は手元にある）→ 戻す
- こちらから返送をお願いして、売れる状態で戻ってきた → 戻す
- **不良品を返送不要のまま返金した → 戻さない**（本は戻ってきていない。ここで
  戻すと在庫が無いのに購入ボタンが復活し、受けられない注文が入る）

戻す場合の手順は `shop.ts` の `restocked` を +1（**`edition` ではない**。
`edition` は法定表示に「本サイトでの販売は◯部」として出るので、いじると
購入者への約束が勝手に増える）。あわせて Stripe の支払い回数上限を
**`edition + restocked`（例: 30 + 1 = 31）** にし直す。`restocked` の値そのもの（1）を
上限に入れないこと — 既に30件売れているので即座にリンクが無効化され、
上限を戻しても復活しない。そのうえで Payment Link を `active=true` にし、
**コードを push する**（`restocked` はコードなのでデプロイしないとサイトの枠は増えない）。

`node scripts/check-payment-link.mjs --live` で確認できるのは **Stripe 側の3点だけ**。
**push 済みかどうかは判定できない**（チェッカーはローカルの shop.ts を読むので、
合格しても本番がまだ古いことがある）。

## Gmailの定型文に入れる

設定 → すべての設定を表示 → 詳細 → **「テンプレート」を有効にする** → 保存。
新規メールの右下「…」→ テンプレート → 下書きをテンプレートとして保存。
以後は同じメニューから呼び出して、2箇所を差し替えて送信するだけ。
